# AI Testing

A showcase of hands-on work at the intersection of AI and software testing, split into two complementary tracks:

| Folder | Focus | Summary |
|---|---|---|
| [`01-using-ai-to-build-tests/`](./01-using-ai-to-build-tests) | AI **as a tool** for testers | Using AI (LLMs, agents, Copilot) to generate, extend, and maintain test automation |
| [`02-testing-ai-llm-systems/`](./02-testing-ai-llm-systems) | AI **as the system under test** | Evaluating and red-teaming LLM/RAG applications for quality, safety, and security |

See each subfolder's README for a resource-by-resource breakdown.
